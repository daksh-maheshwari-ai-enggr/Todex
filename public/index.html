Toodex - AI Coding Assistant

About Toodex

Toodex is an AI coding assistant that helps you write, debug, and optimize code.

It provides an interactive REPL with comprehensive tooling for code analysis, modification, and project management.

Installation

Install Toodex globally using npm:

npm install -g todex

Or use our cURL installation script:

curl -fsSL https://raw.githubusercontent.com/yourusername/todex/main/install.sh | bash

After installation, you can run Toodex in your terminal:

todex "write a function to calculate Fibonacci sequence"

Installation Guide

Follow these steps to install Toodex:

  1. Make sure you have Node.js and npm installed. You can download them from https://nodejs.org/.
  2. Open your terminal and run the installation script:
    3. curl -fsSL https://raw.githubusercontent.com/yourusername/todex/main/install.sh | bash

    Or clone the repository and install manually:

    git clone https://github.com/yourusername/todex.git cd todex npm install npm run build npm link

After installation, you can run Toodex in your terminal:

todex

To run in development mode:

cd todex npm run dev

Usage

To use Toodex, you can either:

  • Run it in one-shot mode with a prompt:
    • todex "write a function to calculate Fibonacci sequence"
  • Start the interactive REPL:
    • todex

Available commands in the REPL:

/help - Show this help /tools - List every registered tool /model - Show the configured model fallback chain /history - Show how many messages are in context /clear - Forget the conversation so far /exit, /quit - Leave the CLI
